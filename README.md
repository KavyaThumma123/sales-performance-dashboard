# Sales Performance & Forecasting Dashboard

## Overview
End-to-end retail analytics solution built on Superstore dataset
(9,994 rows) using SQL, Excel, Power BI and GenAI tools.

## Tools Used
- SQL Server (SSMS) — data engineering and business analysis
- Excel — Power Query cleaning and Pivot Table summaries
- Power BI — 6-page interactive dashboard with DAX measures
- GenAI — hypothesis validation and insight generation

## Key Business Insights
1. Tables and Bookcases are loss-making despite high sales
2. Discounts above 20% consistently produce negative profit
3. West region leads sales — Central has lowest margin
4. Top 10 customers contribute 20% of total revenue
5. Q4 drives 35% of annual revenue — strong seasonality

## Dashboard Pages
1. Executive Summary — KPIs, trends, map
2. Product Performance — category deep dive
3. Regional Analysis — geographic breakdown
4. Customer Intelligence — segment analysis
5. Discount Impact — profitability vs discount
6. Sales Forecast — 6-month prediction

## Files
- sql/analysis.sql — 11 business queries
- excel/sales_cleaned.xlsx — cleaned data with pivot summaries
- powerbi/sales_dashboard.pbix — interactive dashboard

## Dataset
Superstore Sales Dataset — Kaggle
Rows: 9,994 | Columns: 29 after feature engineering
